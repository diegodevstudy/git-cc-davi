## Sobre o projeto
Nosso projeto apresenta como fazer um lanche artesanal.

## Ingredientes
- Pão
- Hambúrguer
- Queijo
- Molhos

## Modo de preparo
1. Coloque o hambúrguer na chapa
2. Deixe grelhar até dourar dos dois lados
3. Monte o lanche com pão, queijo e molhos
